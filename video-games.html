Video Games

This page lists some video games (or online games) that may be useful for learning. Some are explicitly educational, with the goal of helping young people learn basic mathematics or other skills. Others are recreational, but offer something useful for education and development, such as games that can only be mastered through cooperation or games that build problem-solving skills.

Games are updated or changed frequently. Please check for supported platforms to see if the game is available on more platforms than those listed here.

  • An X means the game is (or claims to be) supported on the platform.
  • A red X means you need to perform a workaround of some kind to get the game to work on the particular system. The red X is a link to the instructions for the workaround; link was working as of the date this page was written.
  • A question mark (?) means the site has different games that have specific dependencies to work. Consult the site for details about each game.

Hosting Services

Some of these games can be self-hosted. That gives you an opportunity to create custom versions for your educational purposes, and to reset or re-create games as needed. This is convenient when you want to use a game as part of more than one lesson plan.

Most of these services are not free of charge. Consult each website for current pricing and plans.
